## 📌 Overview

This project investigates the **predictability of extreme events (XE)** in time series generated by complex systems, using a **multifractal cascade framework (p-model)** combined with **LSTM neural networks**.

The central hypothesis explored in this work is:

> Predictability is not solely a property of the learning model, but rather emerges from the **intrinsic multiscale structure** of the underlying dynamics.

We analyze three regimes:

* **Endogenous systems** (internal cascade dynamics)
* **Exogenous systems** (externally driven processes)
* **Mixed systems** (combined dynamics)

---

## 🧠 Methodology

The pipeline implemented in this repository consists of:

1. **Synthetic Data Generation**

   * Multifractal cascade generation using the p-model
   * Controlled intermittency via parameter `p`

2. **Extreme Event Labeling**

   * Identification of rare, high-amplitude events

3. **Modeling**

   * LSTM networks trained to anticipate extreme events

4. **Evaluation**

   * Metrics based on:

     * Recall
     * Anticipation time
     * Regime-dependent performance

## ⚙️ Installation

We recommend using a virtual environment:

```bash
conda env create -f config/environment.yml
conda activate pmodel-env
```

**Environment:**
The experiments were developed and tested on macOS. Dependencies are managed via the provided `environment.yml` file.

## 🚀 Usage

### 1. Generate synthetic data

The p-model generator is implemented in:

```
src/data/pmodel_generation.py
```

This module allows you to create:

* Endogenous cascades
* Exogenous signals
* Mixed regimes

---

### 2. Train the model

Training is handled via:

```
src/training/train.ipynb
```

Configurations are defined in:

```
config/config_*.json
```

Examples:

* `config_endo.json`
* `config_exo.json`
* `config_exo_endo.json`

---

### 3. Evaluate performance

Evaluation scripts:

```
src/training/evaluate.py
```

Outputs include:

* Recall vs anticipation curves
* Regime-based metrics

---

### 4. Load trained models

Pretrained models are available in:

```
results/
```

Files:

* `best_model_endo.pth`
* `best_model_exo.pth`
* `best_model_exo_endo.pth`

## 📈 Key Findings

* Predictability depends strongly on **multiscale cascade structure**
* Endogenous systems exhibit higher predictability
* Mixed regimes reveal transitional behavior
* LSTMs capture temporal dependencies but do not create predictability
